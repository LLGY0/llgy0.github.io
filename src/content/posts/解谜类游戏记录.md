# 星际拓荒（Outer Wilds）
![图](/assets/images/outerwilds.jpg)
平台：PC

类型：解谜＋推理＋第一人称3D＋时空轮回

非常可惜的是，我在玩这个游戏前就看了全流程的攻略了，以至于我真玩上这款游戏时，基本都能按照流程走了，这也是我特别想清除记忆再玩一遍的游戏。市面上的解密游戏真的玩一份少一份，而星际拓荒这种类型也属于少见的类型，科幻+解密可太酷了，当主角驾驶飞船接近巨大的太阳，神奇的彗星，超重的气态巨星以及打呼噜的安康鱼时，那种好奇与恐惧结合的感觉确实奇妙。随着解密进度的推进，一个有趣的故事也随之浮现。个人的努力踩在了数以万计的他人的汗水之上，很难用语言形容通过后的落寞感、完成感、敬畏感。

# 安城密室（Antrim Escape）
![图](/assets/images/antrimescape.jpg)
平台：IOS独占

类型：解谜＋密室逃脱＋2D立绘/背景/道具＋时间穿越

童年回忆，由Game Hive开发的密室逃脱游戏三部曲，但现在想玩都玩不到了（刚需iphone4s附近机型和越狱版系统）。小时候玩这3部的时候，还记得下的圣诞版，一点点收集金币解锁剧情，只能说那时候手游还是太良心了。说回游戏，非常好玩捏，第一部有正常路线和隐藏路线，第二部有双视角解密，第三部将前两部剧情进行收尾，从初始房间后出来真有种柳暗花明的感觉，三人汇合确实感动。印象最深的是元素周期表的解密，感觉已经好久没玩到类似的谜题了....甚至在B站都搜不到相关视频(现在有了)，还是太小众了（PS：而且bgm很好听，一直循环都听不腻）（参考链接：https://www.bilibili.com/video/BV16vTv6DE3b/ ）

# 奥伯拉丁的回归（Return of the Obra Dinn）
![图](/assets/images/returnoftheobradinn.jpg)
平台：PC

类型：解谜＋推理＋第一人称3D＋黑白风格＋海难＋时间穿越

这款游戏我玩到一半还是去翻攻略了，有些谜题确实有点太变态了，前期记人脸也很折磨，而且画面风格原因，部分被爆炸波及区域真的啥都看不清。但不得不说这款游戏题材确实很新颖，有些BGM也很好听。游戏内容为主角使用怀表穿越时空找到所有人的姓名及职业，并还原出事件全貌。这种游戏没有代餐，玩一部少一部，而且最后整理出事件的正确发生顺序还挺有成就感的。推荐所有喜欢解密的玩家玩这个...不过真的很好奇的是，真的有玩家能不靠攻略，不靠猜，不靠瞎填试错，把所有人身份和名称都找到吗

# 蔚蓝（Celeste）
![图](/assets/images/celeste.jpg)
平台：PC

类型：解谜＋2D横版跳跃＋像素＋高难＋"牛抽奖"

是的，我认为蔚蓝其中解谜部分给我带来的快乐大于操作。“为什么要爬山？”“因为山就在那里！”Madeline看了眼“山顶”的图，说了句：“请问地面在哪？”总的来说，这款游戏并没有大家吹的多难（如果你要算mod图，那你赢了），其实难度曲线安排的还算合理（第三章除外），而且登上山顶的爽快感真的是无与伦比，尤其是剧情里madeline让badline享受当下美景时给玩家的满足感。打通这游戏后，我又下载了联机mod，偶尔去简单的图散散步。7A、7C、9A、酱一都是我最喜欢的图（hydra jump接蹭移动墙除外），很喜欢和群友一起爬山的。

# Device 6
![图](/assets/images/device6.jpg)

类型：解谜＋文字游戏＋英语听力

非常新颖的解谜游戏，我是没想到英语听力题都能成为解谜游戏。原本我自信满满的开始挑战（旁边备了有道词典app），但是英语听力实在做不来，甚至大部分信息都是听力给的，直接跪了。但是确实，这个作品很优秀，目前我在市面上没见过第二个这类游戏，值得一试。

# Stanley博士的家 1+2+3
![图](/assets/images/stanley.jpg)
平台：PC＋Android＋IOS(剧情全)

类型：解谜＋密室逃脱＋2D立绘/背景/道具＋时间穿越

对1代和2代现在都还有印象，当年是在4399/7k7k上玩的flash。玩法一般，但这个系列剧情确实不错，3代虽然差评很多，但是在已有框架下还能推陈出新，还能不破坏1和2代的观感，已经很不错了。

# 笼中窥梦（Moncage）
![图](/assets/images/moncage.jpg)
平台：Android＋IOS

类型：解谜＋2D立绘+3D操作+反战题材+父与子

很有意思的解谜，通过旋转视角来拼接物体，继而推动剧情发展。解谜难度较低，但是这作的解谜也是为了剧情作铺垫。之前我玩完完全不知道有真结局...最后云了下真结局，看到漫山遍野的花，确实还挺感动。

# 声之寄托（KOEWOTAYORINI）
![图](/assets/images/koewotayorini.jpg)
平台：IOS

类型：解谜

毕竟古早小众的游戏，解谜不算硬核，比较欣赏的点是很早在手机上做到了对话性解谜（颇有点安乐椅侦探的感觉），甚至还有叙述性诡计。

# KAMI 2
![图](/assets/images/kami2.jpg)
平台：IOS

类型：解谜

在规定步数内将所有区域变成一个颜色。不用多说，简直神作（鸣潮在2.0似乎也借鉴了这个玩法）。

# 小小梦魇系列（Little Nightmares）/ Inside / 地狱边境（Limbo）

类型：解谜＋横版过关

都挺好玩的（小小梦魇3除外），但是都好像啊。

# 画中世界（Gorogoa）/ 致命框架 1+2（FRAMED） 

类型：解谜＋场景转换

游玩逻辑很像的三个游戏，但是都很好玩。

# 纪念碑谷 / 杀出重围Go（Deus Ex GO）/ 杀手Go（Hitman Go）/ 古墓丽影Go（Lara Croft GO）

类型：解谜＋走格子

游玩逻辑很像的几个游戏，但本人对这种类型没什么太大兴趣。尤其是纪念碑谷，作为小众哥，对这个游戏系列被这么多人吹而感到奇怪。

# We Were Here系列

类型：解谜＋双人合作

有好几个系列：本家；Together；Too；The Friendship；Forever。都需要玩游戏最高配置：朋友；虽然不同系列质量参差不齐，但是合作游戏反而看对面才重要，因此玩的时候已经很好玩了。这里就不列举其他双人游戏了（双影奇境、双人成行、逃出生天、泡姆泡姆）。
