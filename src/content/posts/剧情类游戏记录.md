# 魔法使之夜（魔法使いの夜）
![图](/assets/images/witchontheholynight.jpg)
平台：PC

类型：AVG＋Fate

超级厉害的打戏演出，看游乐园打架眼睛快袅袅了...剧情的话，其实感觉不是很特别，就是单纯的boy meet girls，但是这个男主确实有点特别了....

# 艾迪芬奇的记忆（What Remains of Edith Finch）
![图](/assets/images/whatremainsofedithfinch.jpg)
平台：PC

类型：第一人称3D＋家族故事

依然不是因为游戏性而上的安利列表，而是它的故事呈现方式还是挺有趣的，我一直觉得讲故事的同时不让玩家睡着是需要本事的，这部作品确实很让人沉浸进去，会给玩家有种“我倒要看看你下个故事怎么呈现”的感觉，虽然跑图找下个故事的时候有点会让人犯困233。而且这部作品我最喜欢的一点是：它讲的故事的文字，本身也会成为画面的一部分，这可太coolllll了

# 奥日 精灵与森林+精灵与萤火意志（Ori and the Blind Forest + Ori and the Will of the Wisps）
![图](/assets/images/ori.jpg)
平台：PC

类型：2D横版过关

为啥把ori放在剧情类游戏里呢，它又没啥剧情...确实，主要还是因为没别的地方放了，又不想新开个页面记录他...客观的讲，ori最后变树实现传承是非常王道的展开，配上那个1代用到2代的结束BGM，很少有人不感动吧。当时很多人黑ori翻译问题（口口口口口口）。我觉得没毛病，但是这结束的剧情，我还是觉得很好的。我对这游戏唯一不满意的地方，就是把高难沙虫给削了。那天我好不容易把沙虫打过去，通过的一瞬间多么爽啊。现在回去再玩，只感觉眼前的沙虫像几天没吃饭似的，随便打都能过，那高难意义何在，我也不想下载早期的盗版...下面是原评论：

我的横板跳跃启蒙作，没有他我也不可能很快上手蔚蓝。两部综合来看是很老少咸宜的作品，而且几个追逐战的音乐也很好听，好听到可以无限循环几小时。我还是喜欢第二部，略微有点RPG的感觉让跑图更有目标感了，而且ori打架还挺帅。从游戏质量上来看，二代可玩性和剧情都好很多，但是最初发售时bug很多，而且还有“口口”这个梗，但尽管如此体验也还是很好，即使二代，最高难度也不是很高，困难沙虫多试试也能过（你怎么知道我很快就过了困难无削弱沙虫）。很多人吐槽二代剧情，在我看来确实也舍不得ori，但是这故事确实因此而得到了升华，ori以另一种形式存活了下来，并依旧守候他的朋友，一直到死亡。

# 埃里克斯霍姆被偷走的梦（Eriksholm: The Stolen Dream）
![图](/assets/images/eriksholm.jpg)
平台：PC

类型：潜行类＋3D第三人称

我很少玩潜行游戏，觉得躲避敌人视野走格子通常很无聊。但这部还是挺好玩的，难度不高的同时讲的故事还行（一开始确实悬疑拉满，但结局不太行）。放在这部安利也主要因为难得的游戏体验，但总体推荐度肯定不如其他作品。另外，这作品之所以放在剧情作，是因为解谜真的是婴儿难度，基本不会卡关，但其实它剧情也不咋滴，最后结尾实属....但是玩都玩了，而且画面确实不错，把它放进来把。

# 秽翼的尤斯蒂娅
类型：GalGame

好玩，前期悬疑铺垫的很吸引人不断推下去，后期剧情稍微有点拖沓且结尾有点强行Normal END了（本应该是全灭结局）。但是总体来看瑕不掩瑜，是目前八月社所有作品中，我认为唯一能推荐给普通玩家的作品。

# 交响乐之雨
类型：GalGame

画风很让人劝退，但是有我最喜欢的音游要素。虽然我很菜，但还是坚持打完了，剧情意外的不错，歌意外的好听。强烈推荐~

# 牵绊闪耀的恋之伊吕波 / フレラバ ～Friend to Lover～ / 少女领域 / 童貞兄妹
类型：GalGame

专门用于看剧情看累了，缓解下脑子的一些作品（以后废萌作全放里了）。椿姐可爱捏；阳茉莉、奈醋可爱捏；飞鸟凑好可爱啊；

# 水葬银货的伊斯特里亚 / 冥契的牧神节 / 纸上的魔法使 / 宝石少女系列
类型：GalGame

水葬和冥契完全不推荐游玩，简直不是正常人该玩的，剧情中令人吐槽的地方很多。纸魔要吐槽的点很少（除了最后一位女主的塑造和最后一章的剧情），剧情框架上感觉比前两个作品优秀很多，反转也让人看的很爽（不像水葬一眼看出男主就是CA，也不像冥契一眼看出拿了LB的剧本）。宝石少女系列目前只出到第二部，距离完结遥遥无期，但还是很推荐，那么为什么呢？当然是因为我们伟大的桐叶老师的画技更上一层楼了，我永远喜欢桐叶老师，当之无愧的当代毕加索。

# 拔作岛 1＋2（NUKITASHI）
类型：GalGame

很脑洞大开的作品，后期各种玩梗，喜剧感拉满。推荐给不介意黄段子的玩家。

# 潜伏之赤途
类型：AVG

真正的神作，隐形守护者的原作。伟大无需多言，玩过的国产最好的视觉小说。当真无愧最高的山。
